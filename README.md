# sql_pizza_project-

🍕 Pizza Sales Analysis SQL Project
A beginner-friendly SQL project focused on analyzing pizza sales data for a fictional pizzeria. This project includes database creation, table design, data exploration, and SQL queries to derive key business insights.

📘 Overview:
Database: pizzahut

Level: Beginner

Objective: Analyze pizza orders, identify sales trends, and generate business insights using SQL.

📌 Key Features:
Create normalized tables such as orders, order_details, pizzas, and pizza_types.
Retrieve essential metrics like:
Total number of orders
Total revenue
Most popular pizza size
Best-selling pizza
Highest-priced pizza

Join multiple tables to extract meaningful insights

💡 Skills Applied:
SQL Joins, Aggregation, Sorting, and Filtering
Data Modeling & Relational Database Design
Business-Oriented Query Writing

📂 Files:
sql_basic_project.sql: Full script to create the database, insert sample data, and run analysis querie
